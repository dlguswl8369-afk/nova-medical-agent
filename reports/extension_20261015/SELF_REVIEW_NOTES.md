# 공개 사례 자체 검토 — 정성 요약

진료 세션 밖 `openai/gpt-6.1-sol`에 사례별 1회, 총 3회 요청했다. 실제 성공한 대화·진찰 이벤트, 최종 기록, 평가자 전용 공개 사례 원본, 마지막 참고 패킷을 함께 제공했다. 아래는 응답을 검토해 축약한 평가 요약이며 원시 환자 대화나 정답 원문은 아니다. 비맹검 단일 모델의 자체 참고 의견으로, 공식 점수·독립 임상 검증·RAG의 인과 효과를 뜻하지 않는다.

세 응답 모두 영역별 최대 배점만으로 세부 채점 기준을 만들 수 없다는 이유로 숫자 점수를 null로 반환했다. 형식 오류가 아니며 점수를 임의 보충하거나 재호출하지 않았다. 수치 표와 사용량은 [PUBLIC_COMPARISON.md](PUBLIC_COMPARISON.md), [self_review_summary.json](self_review_summary.json)에 보존했다.

## 검색과 기록에서 남은 문제

- **세 사례 모두 마지막 패킷의 직접 관련성이 낮다는 의견**이다. 기존 코딩 사례의 증상 단어 중첩과 운영진 자료의 일반 상담 구간이 선택됐다. 문서 수 증가만으로 실제 검색 품질 개선을 확인하지 못했다.
- C01 확장본의 일부 전달 구간은 제목·저자·소속 중심으로 임상 권고가 없었다. 따라서 JSON의 `nonempty_bodies`는 문자열 존재 여부이며 유용한 근거 본문이 전달됐다는 판정이 아니다. 완결 구간 선택만으로 내용의 유용성이 보장되지 않는다.
- 마지막 참고 패킷과 최종 기록을 대조한 범위에서 다른 환자의 사실이 전이된 명확한 사례는 발견하지 못했다. 전체 시점의 패킷 본문을 보존하지 않았으므로 전체 검색 이력의 혼입 부재는 판정할 수 없다.
- **C03 확장본에는 복합 질문 중 답변되지 않은 항목을 음성 소견으로 확대 기록한 문제가 지적됐다.** 이는 참고자료 혼입과 별개인 관찰 해석 문제다. 관찰 ID·필드 분리·기록 스키마 검증 통과가 문장 수준의 임상 사실 정합성을 보장하지 않는다.
- C10 양쪽 기록에는 동일 초기 관찰의 중복 표현이 지적됐다. 반복 측정으로 인정할 수 없다. 검사·치료·추적 계획도 실제 수행 여부와 구분해야 한다.

후속 검토 우선순위는 대상 연령·임상 주제에 맞는 검색 선택, 제목/서지 위주 구간 제외, 복합 질문의 미응답 항목 재확인, 관찰별 기록 문장의 정합성 검사다. 이번 비교의 앱·후보를 중간에 변경하거나 추가 세션으로 결과를 교체하지 않았다. 임상 전문가의 별도 검토와 추가 사례 평가가 필요하다.

원시 평가 응답과 실행 원장은 저장소 밖 `nova_extension_work_20261015/private_comparison/`에 보존했다. Git에는 이 요약과 비밀값 없는 집계만 포함했다.
