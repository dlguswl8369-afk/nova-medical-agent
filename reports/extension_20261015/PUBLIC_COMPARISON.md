위 초 단위 시간은 준비·진료·후속 서버 상태 조회를 포함한다. 아래 차이 표는 앱이 보고한 진료 시간만 비교한다. C10 v3.3은 최종 DIAGNOSE의 서버 completed 응답 후 읽기 전용 상태 조회가 시간 초과됐다. 보존한 성공 응답으로 완료 상태를 정리했으며 새 세션이나 진료 재실행은 없었다. 원래 실패 상태와 원시 응답 해시는 별도로 보존했다.
Windows 실제 API 실행의 프로세스 메모리 표본은 `api_process_resource_samples.json`에 있다. 일부 시점의 관측으로 전체 피크를 보장하지 않으며, 별도 Linux 오프라인 검증의 cgroup 제한 측정과 구분한다.

## 여섯 영역 자체 참고 평가

세 응답 모두 세부 채점 기준 부족으로 수치 점수를 부여하지 않았다. 아래 미측정은 요청 실패가 아니라 점수 미산정이다. 영역별 비교 의견과 검색·기록 문제는 [SELF_REVIEW_NOTES.md](SELF_REVIEW_NOTES.md)에 요약했다.

모델: openai/gpt-6.1-sol, reasoning=medium, 최대 출력 4,000토큰, 사례별 1회, 진료 세션 ID 없음. 로그·최종 기록·공개 사례의 평가자 전용 원본·마지막 참고 패킷을 함께 제공했다. 비맹검 단일 모델의 비교이며, 웹사이트 진행 중 채점과 무관하다. 응답 스키마/점수 범위가 맞지 않으면 미확인으로 표시하고 재호출하지 않는다.
