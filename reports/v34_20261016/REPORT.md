**C03 음성 확대의 정확한 위치는 A.differential**이다. S.ros는 질문과 실제 답변 원문을 보존했지만, A의 자유 서술이 부분 답변을 여러 항목의 음성으로 확대했다. 기존 관찰 ID 검증은 인용 ID의 존재·종류만 검사해 문장 의미의 과장을 막지 못했다. RAG의 다른 환자 사실 복사와는 구별되는 문제다.

마지막 검색 패킷은 세 사례 모두 직접 관련성이 낮다는 자체 검토 의견이 있었고, C01에는 제목·서지 위주 구간도 있었다. 다만 전체 패킷 본문·동일 조건의 RAG 단독 대조·웹사이트 해당 로그가 없으므로 **진단추론 점수 하락의 원인이라고 확인하지 못했다**. 검색 자료와 순위 알고리즘은 추가/변경하지 않고, 관련성이 없으면 판단에 사용하지 않도록 프롬프트 경계를 강화했다.

## 변경 동작

1. 환자별 정보 공백·부분/모호 답변 상태와 관찰 원문 인용을 분리한다. 매 행동에 단일 대상·필요 이유를 요구하고, 명백한 복합 표현을 재생성한다. 공개 사례의 진단이나 전용 질문 순서를 넣지 않았다.
2. 실제 SAY 성공 응답을 확인한 설명만 별도 상태와 P.education에 반영한다. DONE 전에 정보·설명 상태를 검토하고, 필요한 미전달 설명이나 추가 질문을 선택한다. 고정 횟수 대신 환자별 사유와 남은 자원을 사용한다.
3. 시간·턴·모델 예산에 따라 마무리 설명을 우선하고, 최종 기록 예약 외에 설명 선택 여유를 조건부로 확보한다. 새로운 고위험 질문은 우선할 수 있다.
4. 반복 길이 오류는 더 짧은 생성 목표로 복구한다. 자동 절단·TEST→EXAM 변경은 하지 않는다. 새 응답은 다시 검증하고 3회 한도·원래 request_id 재시도·예산 정산을 유지한다.
5. S/O의 확보 원문 누락을 줄이고 활력징후 중복을 제거한다. A의 자유 서술에서 새 정상/음성 문장을 보수적으로 거절하고, 확인된 음성은 관찰 원문으로 보존한다. 반복 기록 실패 시 원문 기반 fallback을 사용한다.

구현 위치·설정·제약은 [CONSULTATION_V3_4.md](../../docs/CONSULTATION_V3_4.md)에 있다.

## 아직 확인하지 못한 것

- v3.4 실제 모델의 질문 선택·공감·설명 정확성, 새로운 메타데이터 형식 준수, 토큰/호출/시간 변화, 안전 점수 유지 및 대회 점수 개선은 **미평가**다.
- 복합 질문·정상/음성 검사는 보수적 문구 검사다. 오탐·누락, 의미가 같은 다른 표현, 근거 없는 양성 소견까지 완전 검증하지 못한다. 임상적으로 맞는 가설 서술을 거절해 재시도·비용이 늘 수도 있다.
- 중요도·질문 필요성·설명 태그·종료 예외 이유는 모델 판단이다. 태그가 실제 발화의 임상적 적절성이나 환자의 이해·이행을 보증하지 않는다.
- 긴 문맥의 `visible_facts` 한도로 제외된 관찰, 전 시점 검색 근거, 실제 모델의 의미 보존 단축은 추가 확인이 필요하다.
- v3.3의 Linux 통과 기록을 v3.4에 재사용하지 않는다. 이번에는 VM·컨테이너 자원 제한 재검증·공식 제출을 하지 않았다.
